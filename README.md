# Shopping Cards

Ранний учебный проект (2022): каталог товаров на React и TypeScript.

- товары грузятся из [Fake Store API](https://fakestoreapi.com) через кастомный хук `useProducts`, с состояниями загрузки и ошибки
- модалка создания товара через React Context
- роутинг между каталогом и страницей «О проекте»

`React 18` `TypeScript` `React Router 6` `Axios` `Tailwind CSS`

## Запуск

```bash
npm install
npm start
```
